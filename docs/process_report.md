# ScamShield — AgentReel A05: Process Report (Pre-submission draft)

**Brief and audience.** ScamShield addresses A05 cyber safety for college students, focusing on fake internship/job messages and impersonation-based “digital arrest” scams. The ~53.26-second English reel uses a direct hook, illustrative fictional scenarios, prevention advice and an official reporting call to action: cybercrime.gov.in and 1930 (specifically for financial cyber fraud). It closes with a college-logo end card and an AI-generation disclosure.

**System and agent graph.** The workflow is Planner (Groq) → Researcher (Groq over curated source notes) → Scriptwriter (Groq/local fallback) → Storyboarder (rule-based) → Asset Generator (Pillow) → Narrator (Edge-TTS) → Editor (FFmpeg) → Critic (technical/metadata checks). Each stage hands a file artifact to the next, mostly JSON plus generated images, MP3s and video. The project uses a custom Python orchestrator instead of a separate multi-agent framework. The final college-logo card was added in a separate human-reviewed edit and is not reproduced by the current editor stage.

**Grounding and creative decisions.** The Researcher records claims and source IDs, validating that quoted evidence occurs in local curated notes. This is not independent verification of the original web/PDF sources. A fake-internship fee demand is shown as a *warning sign*, not evidence that every fee request is fraudulent. Fictional interfaces avoid showing real victims or impersonating real student/faculty likenesses. Human revisions tightened the script and layout; rule-based visual mockups were used rather than a generative image service.

**Production results.** The accepted reel is approximately 53.261 s, 1080×1920, 25 fps, H.264 High profile (`yuv420p`), AAC stereo/48 kHz and about 1.54 MB. Narration pacing was shortened by adapting scene lengths to recorded speech. The QA Critic produced 14 PASS, 1 FAIL and 10 REVIEW: the observed integrated loudness was −21.0 LUFS versus the assignment target of about −14 LUFS; the user chose to preserve it. The 13-cue SRT passed automated time-bound and overlap checks, but speech-level alignment and mobile readability are manual-review items. A decorative heading slightly enters the upper platform safe zone.

**Reproducibility, autonomy and Critic feedback.** `run.py --mode check` verified expected inputs, and `--mode qa` executed Critic and logged the result. A separate-copy full-generation test reached Planner and Researcher; Scriptwriter then rejected mismatched/missing topic categories. An attempted compatibility patch in that disposable test copy failed with an indentation error. The original approved production artifacts were not changed. Hence end-to-end regeneration and an autonomous repair loop are **not validated**. The Critic reports PASS/FAIL/REVIEW but does not rewrite or regenerate defective media. The system is best described as a supervised, partially orchestrated AI-assisted workflow; do not claim fully autonomous L3/L4 behavior.

**Costs and human interventions.** Genuine stage timings from one integration run: Planner 2.002 s; Researcher 5.622 s; Scriptwriter exited with error after 0.255 s. Planner token counts and other logged figures may exist in the source logs, but a complete reconciled cost table is **not available**. Record unknown usage/cost as “not recorded” rather than zero. Human interventions included creative/script revisions, timing and layout fixes, independent logo incorporation and decision to keep the loudness deviation; exact historical counts/timestamps require retrospective qualification and must not be represented as real-time instrumented records.

**Limitations and next actions.** Review all original government sources, including the 1930 financial-fraud distinction; obtain evidence the college logo is authorized; complete Category A human-safety approval; inventory asset licenses and prompts; finish a truthful cost/intervention record and README. The written brief requests one-command reproducibility and a feedback loop, which remain limitations despite the faculty's reported allowance to demonstrate a pre-rendered reel. Only after final file and privacy checks should the repository receive tag `v1.0-final`.
